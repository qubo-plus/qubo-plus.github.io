/ "C++ version" link) qbpp_mode_href — target of the C++/Python button: qbpp_mode_exact, or the other mode's top page (DOCUMENT) when there is none qbpp_lang_href — target of the EN/JA button: the same page in the other language, or that language's home when there is none All three are "" on pages outside en/ and ja/ (root redirect stubs). {%- endcomment -%} {%- assign qbpp_mode_exact = "" -%}
